# מנוע ניקוד לעברית רבנית

מנוע ניקוד המותאם לעברית רבנית ולארמית תלמודית, בנוי לפי תוכנית העבודה
שבשורש הפרויקט. ה-API הוא פונקציה אחת:

```python
from engine import nikud
nikud("אמר רבי עקיבא")      # → 'אָמַר רַבִּי עֲקִיבָא'
```

## למה זה נבנה

DictaBERT-char-menaked, המודל החזק ביותר שקיים היום לניקוד עברי, אומן על
עברית מודרנית. כרטיס המודל קובע במפורש שאינו מיועד לשכבות מוקדמות —
מקראית, רבנית או טרום־מודרנית. הפער הזה, ולא איכות המנוע, הוא מקור רוב
השגיאות בטקסט רבני.

המנוע כאן לא מחליף את המודל אלא עוטף אותו בשכבות שיודעות את מה שהוא לא
יודע: לקסיקון מהקורפוס הרבני, הכרעה לפי הקשר, והעתקת ניקוד ישירות מהמקור
כשהטקסט מצטט.

## הקו האדום

**אחרי הסרת כל הניקוד הפלט חייב להיות זהה למקור תו־בתו.** זו לא בדיקה
מייעצת — `Engine.vocalize` לא מחזיר טקסט שלא עבר את `assert_identity`,
וכל שכבה שמחזירה צורה ששלדה שונה נפסלת בלי להשפיע על הפלט. טקסט שנאכל
גרוע מניקוד שגוי.

## התקנה

```bash
pip install torch transformers datasets accelerate \
            requests tqdm python-docx numpy
```

Python 3.11+. GPU נדרש רק לשלב 4 (אימון). כל השאר רץ על CPU.

## שימוש

```bash
make test                                   # הבדיקות, כולל הקו האדום
make fetch                                  # משיכה מספריא (fetch-safe = בלי CC-BY-NC)
make eval-set                               # סט הערכה מוקפא — פעם אחת בלבד
make corpus lexicon quotes
make baseline                               # reports/baseline.md
make book BOOK=path/to/book.docx            # docx מנוקד, העיצוב נשמר
```

ניקוד מהיר משורת הפקודה:

```bash
python src/engine.py --engine full --stats "אמר רבי עקיבא לתלמידיו"
```

## רישוי הנתונים

`data/LICENSES.md` נכתב אוטומטית בזמן המשיכה, לא אחריה.

התלמוד המנוקד בספריא (מהדורת ויליאם דוידסון) הוא **CC-BY-NC**. לספר פרטי
זה בסדר גמור; למוצר או שירות מסחרי — לא. למסלול מסחרי:

```bash
make fetch-safe
python src/build_corpus.py --commercial-safe
```

זה מוריד את התלמוד ומשאיר תנ"ך (CC-BY-SA), משנה (נחלת הכלל) וסידור.
עדיף לאמן פעם אחת על הסט הנכון מאשר לגלות בדיעבד שהמודל נגוע.

## מה לא ייפתר

הומוגרפים שתלויים במשמעות ולא בתחביר. זָכָר מול זֵכֶר נחתך לפי מה שהמחבר
התכוון, ואין בטקסט סימן תחבירי שמכריע. הצורות האלה נשארות ב-
`lexicon/review_queue.json` ובתור של `src/review.py`, ולא מנוקדות על סמך
ניחוש.

המטרה היא לצמצם את ההגהה, לא לבטל אותה. מנוע שמסמן נכון 100 מילים לבדיקה
שווה יותר ממנוע שמנחש 100 מילים בביטחון.

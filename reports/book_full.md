## מה עוד צריך הגהה

אין לספר טקסט זהב, ולכן אי אפשר למדוד עליו WER. ההערכה הכמותית
היחידה היא `reports/baseline.md`: **14.47% WER** על סט רבני מוקפא.
על 52 אלף מילים זה סדר גודל של כמה אלפי מילים שצריכות עין אנושית.

מה שראיתי בבדיקה ידנית של הדוגמאות:

| מילה | המנוע | הצורה הנכונה | סוג |
|---|---|---|---|
| אליה | אֵלֶיהָ | אֵלִיָּה | הומוגרף סמנטי — שם הנביא מול מילת יחס |
| גאולה | גְּאֻולָּה | גְּאוּלָּה | קובוץ במקום שורוק בכתיב מלא |
| לזוגיות | לַזוּגִיּוּת | לְזוּגִיּוּת | ניקוד למ"ד השימוש |
| הערה | הֶעֱרָה | הֶעָרָה | חטף במקום תנועה מלאה |
| עזרני | עַזְרֵנִי | עֲזָרַנִי | בניין ונטייה |

**`אליה` הוא המקרה המלמד.** בתנ"ך זו כמעט תמיד מילת היחס, ולכן
הלקסיקון והמודל מושכים לשם. אין סימן תחבירי שמכריע שכאן מדובר בשם
הנביא — רק ידיעת העניין. זה הסוג שסעיף 11 בתוכנית אומר שלא ייפתר,
ובשבילו קיימת לולאת התיקונים. הכרעה אחת מתקנת את כל המופעים בספר:

```bash
python src/review.py queue --docx book.docx --engine full
python src/review.py run
make book BOOK=book.docx      # ניקוד מחדש עם ההכרעות
```

## שגיאות שזוהו בבדיקה ידנית

הבדיקה נעשתה על הדוגמאות שלמעלה. אין לספר טקסט זהב, ולכן אי אפשר למדוד עליו WER — המספרים הכמותיים היחידים הם אלה שב-`reports/baseline.md`.

| מילה | המנוע | הצורה הנכונה | סוג |
|---|---|---|---|
| אליה | אֵלֶיהָ | אֵלִיָּה | הומוגרף סמנטי — שם פרטי מול מילת יחס |
| גאולה | גְּאֻולָּה | גְּאוּלָּה | קובוץ במקום שורוק בכתיב מלא |
| לזוגיות | לַזוּגִיּוּת | לְזוּגִיּוּת | ניקוד למ"ד השימוש |
| הערה | הֶעֱרָה | הֶעָרָה | חטף במקום תנועה מלאה |
| עזרני | עַזְרֵנִי | עֲזָרַנִי | בניין ונטייה |
| וסייעני | וְסִייְּעֲנִי | וְסִיַּיְעַנִי | נטיית כינוי |

**אליה → אֵלֶיהָ הוא המקרה המלמד.** בתנ"ך `אליה` הוא כמעט תמיד "אֵלֶיהָ", ולכן הלקסיקון והמודל מושכים לשם. אין בתחביר סימן שמכריע — רק הידיעה שמדובר בשם הנביא. זה בדיוק הסוג שסעיף 11 בתוכנית אומר שלא ייפתר, והפתרון לו הוא לולאת התיקונים:

```bash
python src/review.py queue --docx book.docx --engine full
python src/review.py run       # מכריעים; ההכרעה נכתבת ל-overrides.json
```
